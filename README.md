# Dev Project Backup

Εφαρμογή για τοπικά backups προγραμματιστικών projects, με γραφικό περιβάλλον σε CustomTkinter.

## Δυνατότητες

- Καταχώριση project, τοπικού φακέλου και γλώσσας προγραμματισμού.
- Δημιουργία συμπιεσμένων snapshots: το όνομα έκδοσης χρησιμοποιείται και για το όνομα του ZIP.
- Αυτόματη παράλειψη συνηθισμένων generated φακέλων ανά γλώσσα.
- Ιστορικό εκδόσεων με ημερομηνία και μέγεθος.
- Επαναφορά έκδοσης σε φάκελο που επιλέγει ο χρήστης.
- Αυτόματο safety backup πριν από επαναφορά πάνω στον αρχικό φάκελο του project.
- Ανάγνωση `.gitignore` και custom exclusions ανά project.
- Προεπισκόπηση πλήθους/μεγέθους αρχείων πριν από κάθε backup.
- Εντοπισμός πιθανών secrets και αρχείων μεγέθους τουλάχιστον 100 MB.
- Επιλογή ξεχωριστού φακέλου αποθήκευσης backup ανά project.
- Αφαίρεση project από τον κατάλογο χωρίς διαγραφή των υπαρχόντων ZIP.
- Όλα τα δεδομένα μένουν τοπικά στον υπολογιστή του χρήστη.

## Εκτέλεση

Απαιτείται Python 3.10 ή νεότερη. Από PowerShell, στον φάκελο του project:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python .\scr\main.py
```

Στο γραφικό περιβάλλον, πρόσθεσε τον φάκελο ενός project και έναν φάκελο
αποθήκευσης ZIP, γράψε όνομα έκδοσης και επίλεξε **Δημιουργία backup**.
Πριν από τη δημιουργία εμφανίζεται προεπισκόπηση των αρχείων. Αν υπάρχει ήδη
ZIP με το ίδιο όνομα, η νέα έκδοση παίρνει αριθμημένο όνομα (π.χ. `_2.zip`).

Σε κανονική εκτέλεση, το catalogue αποθηκεύεται στον φάκελο δεδομένων της
εφαρμογής που ορίζει το λειτουργικό σύστημα. Στα Windows:

```text
%LOCALAPPDATA%\DevProjectBackup\
└── catalogue.json
```

Ο χρήστης επιλέγει ξεχωριστά τη θέση των ZIP για κάθε project και τα αρχεία
αποθηκεύονται απευθείας μέσα σε αυτή, χωρίς αυτόματο υποφάκελο. Η προτεινόμενη
production τοποθεσία είναι `Documents\DevProjectBackups\`. Η εφαρμογή
δεν επιτρέπει ο φάκελος backup να βρίσκεται μέσα στον φάκελο πηγαίου κώδικα.
Αν αλλάξει η τοποθεσία, επηρεάζονται μόνο τα επόμενα backups.

Οι προεπιλεγμένες εξαιρέσεις καλύπτουν συνηθισμένα παραγόμενα αρχεία ανά γλώσσα.
Προαιρετικά εφαρμόζεται το `.gitignore` στη ρίζα του επιλεγμένου project και
μπορούν να οριστούν επιπλέον εξαιρέσεις από τις ρυθμίσεις του. Πιθανά secrets,
όπως `.env` και ιδιωτικά κλειδιά, εξαιρούνται από προεπιλογή· η συμπερίληψή τους
απαιτεί ρητή επιλογή στις ρυθμίσεις. Η προεπισκόπηση επισημαίνει επίσης μεγάλα
αρχεία, αλλά δεν τα εξαιρεί αυτόματα.

Η επαναφορά εξάγει το ZIP στον φάκελο που επιλέγεις. Αρχεία με ίδιο όνομα μπορεί
να αντικατασταθούν, ενώ άλλα υπάρχοντα αρχεία παραμένουν εκεί. Αν επιλέξεις τον
αρχικό φάκελο του project, δημιουργείται πρώτα safety backup της τρέχουσας
κατάστασης.

## Development mode

Στο VS Code, άνοιξε το **Run and Debug** (`Ctrl+Shift+D`) και επίλεξε:

- `Dev Backup: Development` για δεδομένα στο `.devdata/`.
- `Dev Backup: Production` για catalogue στο `%LOCALAPPDATA%\DevProjectBackup` και
  προτεινόμενα backups στο `Documents\DevProjectBackups`.

Εναλλακτικά, για εκτέλεση από PowerShell με δοκιμαστικά δεδομένα απομονωμένα
μέσα στο project:

```powershell
$env:DEV_BACKUP_ENV = "development"
python .\scr\main.py
```

Τότε χρησιμοποιείται ο φάκελος `.devdata/`, ο οποίος αγνοείται από το Git:

```text
.devdata\
├── catalogue.json
└── archives\
```

Για επιστροφή σε production mode στην ίδια συνεδρία PowerShell:

```powershell
Remove-Item Env:DEV_BACKUP_ENV
```

Σε μελλοντικά tests μπορεί να περνά προσωρινός φάκελος απευθείας ως
`BackupManager(temp_directory)`, χωρίς να επηρεάζουν κανένα από τα παραπάνω δεδομένα.
